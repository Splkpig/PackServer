This is a collection of all (as far as I know) public PitPacks.

Each pack is zipped so you only need to place the .zip in your ResourcePacks folder (no unzipping necessary).

To download one simply click on it above and click download raw file.

If you want all of them, navigate to your ResourcePacks folder and run "git clone https://github.com/Splkpig/PackServer.git". 
- This requires you to have git installed. 
- Alternatively, from the green Code dropdown you can download a zip file of all the packs. Place this in your ResourcePacks folder and unzip it.
